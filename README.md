API Dashboard

Аналитическая панель на JavaScript, работающая с данными REST API.

Возможности

- получение данных через REST API
- отображение статистики
- график на Chart.js
- поиск пользователей
- сортировка
- пагинация
- обработка ошибок
- индикатор загрузки
- адаптивная вёрстка

Технологии

- HTML5
- CSS3
- JavaScript (ES6+)
- Fetch API
- Async/Await
- REST API
- Chart.js
- Git / GitHub
- GitHub PagesI

Данные получаются из DummyJSON API.

Проект создан для практики работы с API, асинхронным JavaScript, обработкой данных и построением интерфейсов на основе полученной информации.
